# Lesson 07: Capstone

## What this is

A small, testable workflow combining inference, tools, persistence, and validation.

## Why it matters

A hello-world proves connectivity. A capstone proves understanding.

## Build it

Give Hermes three public or synthetic Markdown files and ask for a sourced briefing with open questions and a verification checklist.

## Check it

Verify that every input filename is cited, unsupported claims are avoided, and the output survives a restart.

## Break it

Add one contradictory input and rerun the workflow.

## Fix it

Improve the skill or instructions so contradictions are surfaced instead of hidden.

## Keep it

Record provider, model, attempts, tool failures, final result, and limitations. Share only sanitized evidence.
