# Lesson 06: Skills and MCP

## What this is

Skills teach repeatable procedures. MCP exposes external tools and context.

## Why it matters

Procedures and capabilities solve different problems and create different risks.

## Build it

Use the Hermes dashboard to create a narrow skill that states the outcome, assumptions, process, validation, and limitations. Review current Hermes MCP documentation before connecting any server.

## Check it

Run the same task three times and verify the procedure remains recognizable.

## Break it

Remove the validation instruction and compare the output.

## Fix it

Restore validation. Qualify any MCP server for permissions, credentials, data exposure, health, removal, and prompt-injection risk.

## Keep it

Document the skill's trigger, input, output, test prompt, and failure modes.
